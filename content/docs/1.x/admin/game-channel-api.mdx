## Overview

The game channel admin API lets you create, update, delete and list [game channels](/1.x/http/game-channel-api) programmatically, as well as read their storage props.

### RejectedProp

```ts
type RejectedProp = {
  key: string
  error: 'PROP_KEY_TOO_LONG' | 'PROP_VALUE_TOO_LONG' | 'PROP_ARRAY_TOO_LONG' | 'PROP_CONTAINS_PROFANITY' | 'PROP_KEY_RESERVED'
  message: string
}
```

Creating or updating a channel whose props fail the size or profanity checks returns `400` with `errors.props` and a `rejectedProps` array.
