## Overview

The game config admin API lets you read and update your [live config](/1.x/http/game-config-api) programmatically, as well as schedule future changes. This is useful for automating changes like raising the level cap ahead of a patch or enabling an event at a specific time.

Reading config requires the `read:gameConfig` scope. Updating config and managing scheduled changes requires the `write:gameConfig` scope.

## Types

### ScheduledGameConfigChange

A scheduled change is applied at `applyAt`. Setting `value` to `null` deletes the prop instead of updating it.

```ts
type ScheduledGameConfigChange = {
  id: number
  key: string
  value: string | null // null deletes the prop when the change is applied
  applyAt: string
  createdAt: string
}
```
